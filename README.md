🌐 IoT ProjectsBem-vindo ao meu repositório de Internet das Coisas (IoT) e Sistemas Embarcados.Aqui encontra uma coleção de projetos pessoais e profissionais que venho a desenvolver. O objetivo principal deste repositório é explorar a integração entre hardware e software, criando soluções físicas para problemas reais através de prototipagem, recolha de dados e automação.🛠️ Tecnologias e Hardwares UtilizadosAo longo dos projetos neste repositório, utilizo uma variedade de microcontroladores, linguagens e protocolos de comunicação:Hardware: ESP32, Arduino, Raspberry Pi, Sensores e Atuadores.Comunicação: Protocolo LoRa, Wi-Fi, Bluetooth/BLE, MQTT.Software & Linguagens: C/C++, Python.Design: Prototipagem de circuitos e Modelagem 3D.📂 Estrutura do RepositórioAbaixo estão os principais projetos contidos neste repositório.
