Bem-vindo ao meu repositório de **Internet das Coisas (IoT)** e **Sistemas Embarcados**.

Aqui encontra uma coleção de projetos pessoais e profissionais em desenvolvimento contínuo. O objetivo principal é explorar a integração entre hardware e software — criando soluções físicas para problemas reais através de prototipagem, recolha de dados e automação.

## 🚀 Como Utilizar

**1. Clone o repositório**
```bash
git clone https://github.com/neuxxkk/IoT-projects.git
```

**2. Abra o projeto**

Utilize o **Arduino IDE** ou o **PlatformIO (VS Code)** para abrir a pasta do projeto desejado.

**3. Instale as dependências**

Certifique-se de instalar as bibliotecas de terceiros mencionadas no cabeçalho de cada ficheiro `.cpp` ou `.ino`.

**4. Upload**

Selecione a placa e a porta COM corretas e faça o upload para o seu dispositivo.
